# Toxica 🐢

**Safer screens. Stronger bonds.**

Toxica is a **hackathon prototype** of a parent-managed Chrome extension that pauses potentially harmful Reddit discussions and helps parents turn them into conversations with their children. It is designed with **ages 6–15** in mind.

Rather than simply hiding a thread, Toxica predicts whether the discussion might become toxic, asks for a parent to review flagged content, and offers conversation prompts generated by Gemini with examples retrieved from the **SpecialTime parent–child communication dataset**.

> **Status:** Local demonstration/prototype, not a production parental-control product, clinical intervention, or tamper-proof safety solution. The toxicity predictions and communication advice have not been clinically validated for ages 6–15.

## How it works

1. A child opens a Reddit discussion with Toxica installed and paired to a parent account.
2. The extension collects the post context and available comments. The backend requires **at least five comments** to run its trained prediction model; if insufficient data or the ML service is unavailable, it shows an unavailable/safety-cover state rather than declaring the discussion safe.
3. The local **Python ML service** uses Toxic-BERT scores for the first five comments plus text and thread features, feeding a trained **Logistic Regression** classifier. The result is displayed as `safe`, `low`, `medium`, or `high`.
4. Safe threads can proceed. Flagged threads are paused for review; if the parent has already blocked that toxicity level, the child is redirected away instead.
5. A parent opens the review window and **enters their PIN before flagged post content or coaching is revealed**. They can **Allow this thread** or **Block this toxicity level for 30 days**.
6. The parent sees three short suggestions under **Context · Ask · Reflect**. Gemini generates them from the discussion plus relevant, labeled SpecialTime statements, with built-in generic advice as a fallback if Gemini is unavailable.

The waiting screen has a small **turtle runner** along the top of the white card. On the **Waiting for a parent** screen only, press **Space** or **↑** to jump over obstacles; the game does not determine or modify safety decisions. The latest runner version uses a higher jump and a refined Canvas-drawn turtle.

## Features

- **Conversation-level early warning:** uses the first five available comments, not a keyword blacklist. The extension's available comments may not always be the first five in true chronological order.
- **Parent-verified decisions:** flagged content and guidance are behind PIN verification. Five incorrect PIN attempts trigger a five-minute lockout.
- **30-day category rules:** parents can block a whole predicted risk tier or reset the blocks from their portal.
- **Device pairing:** six-digit code, valid for ten minutes; protection is bound to a browser installation and can retain observed Reddit usernames across account switches.
- **Research-informed coaching:** uses **SpecialTime/DPICS** parent-statement labels to shape response *style*, while Gemini adapts wording to the actual topic.
- **Fallback behavior:** generic advice remains available when Gemini fails, and the safety check does not silently fall back to a keyword-based prediction.
- **Branded UI:** forest-green child/review surfaces, cream review cards, and a softer sage parent management portal. The original Toxica logo is retained.

## Requirements

- macOS (commands below), or an equivalent shell environment on another OS
- **Node.js 18+**
- **Python 3.11 or 3.12** recommended for the ML environment
- **Google Chrome** with extension Developer mode
- A **Gemini API key** (optional; without it, built-in conversation tips are displayed)
- Internet access for Google Gemini and, on first use, download of Toxic-BERT weights
- Both computers on a trusted network if the parent portal is accessed from a second device

## Run locally

Open **two VS Code terminals**, with the repository root as your starting directory.

### Terminal A — Python ML model

```bash
cd backend/ml_service
python3 -m venv .venv               # first time only
source .venv/bin/activate
python -m pip install -r requirements.txt  # first time only
python -m uvicorn app:app --host 127.0.0.1 --port 8766
```

Keep this running. Check **http://127.0.0.1:8766/health**. The local `.pkl` model must be present. Only load pickle/model files from trusted sources.

### Terminal B — Node backend + Gemini

```bash
cd backend
```

**Option A: Supply your API key in the current terminal session.** Enter it interactively (typing is hidden):

```bash
read -s GEMINI_API_KEY
export GEMINI_API_KEY
GEMINI_MODEL=gemini-3.6-flash node server.js
```

`gemini-3.6-flash` is the model **confirmed to respond to a direct API request** during development. Its availability can change, and a direct response does not guarantee that the full Toxica coaching request will succeed. Set `GEMINI_MODEL` to another model your API key supports if needed. The earlier integration's `gemini.js` defaults to `gemini-3.8-flash` unless you change or override it.

**Option B: Persistent local `.env` (optional).** If you've installed `dotenv` and added `require('dotenv').config();` **before** loading the Gemini module in `server.js`, you may use:

```dotenv
GEMINI_API_KEY=your_actual_key_here
GEMINI_MODEL=gemini-3.6-flash
```

Then run `node server.js`. **An `.env` file is not loaded automatically by the original dependency-free backend**; use Option A unless you've explicitly enabled dotenv. Do not put API keys in source files or commit `.env`.

Parent portal: **http://localhost:8787**  
Backend status: **http://localhost:8787/api/health**

### Install/reload the Chrome extension

1. Open **`chrome://extensions`**, enable **Developer mode**, and choose **Load unpacked**. Select the **`chrome-extension/`** folder.
2. In the extension's setup popup or options, configure the backend URL (usually `http://localhost:8787`) and pair with a parent account.
3. If the extension is already installed, click **Reload** rather than removing/reinstalling it; reinstalling may reset the browser's pairing state.
4. Refresh the Reddit page after reloading.

### Set up a parent account and pair a browser

1. Open **http://localhost:8787**. Create a parent account using an email, password (at least eight characters), and **4–8-digit PIN**.
2. In the parent portal, generate a **six-digit pairing code**.
3. Enter that code using the Toxica extension on the child's Chrome browser within ten minutes.
4. Browse a Reddit post containing at least five available comments. For a flagged thread, ask a parent to review, enter the PIN in the separate review window, and choose **Allow this thread** or **Block [level] Toxicity for 30 Days**.
5. Use the portal to inspect paired browsers, view/change the PIN, or reset blocks.

**Second-device access:** For a parent on the same Wi-Fi network, open `http://<your-computer-local-IP>:8787` instead of `localhost`. This prototype serves HTTP without TLS; use only on a trusted network and do not expose port 8787 to the public internet.

## ML model: what is predicted?

The Python service at `127.0.0.1:8766` receives the title/body, first five available comments, and thread metadata. It uses **`unitary/toxic-bert`** to derive early-comment toxicity scores and then applies a trained **Logistic Regression** model with text and numeric features.

The output contains a decision margin, threshold and one of four display buckets. **Low/medium/high are exploratory thresholds on model decision margins—not validated probabilities, severity diagnoses, or age-specific clinical risk ratings.** A high model score does not prove the thread is harmful; it estimates risk using the trained data and features.

If fewer than five comments are available, or the Python service fails, the backend returns an `unavailable` action rather than approving the discussion.

## Gemini + SpecialTime: research-informed parent guidance

### Research dataset

**SpecialTime: Automatically Detecting Dialogue Acts from Speech to Support Parent-Child Interaction Therapy**, Huber et al. (2019), Harvard Dataverse.  
Source: **https://doi.org/10.7910/DVN/C5Z3SC**

Your downloaded CSV contains **6,021 records** with the original columns:

| Column | Meaning |
|---|---|
| `label` | DPICS-style parent communication category |
| `child talk` | Example child statement when supplied |
| `parent talk` | Therapist-authored parental utterance |

The integration normalizes these into `specialtime.json`. It preserves all original data but selects coaching examples only from **reflection, labeled/unlabeled praise, questions, and behavior descriptions**. The retrieval code currently loads **3,077 eligible statements** and chooses up to four category-balanced examples through lightweight keyword overlap and style selection.

The statements are **therapist-written illustrations**, not recorded or proven-effective responses for every child. Many deal with play situations or younger children rather than online safety; Gemini is asked to **learn communication style, not copy their subjects or wording**.

### Generation flow

1. Backend flags a thread, then starts generating coaching asynchronously while the child waits.
2. `parenting_retrieval.js` loads and selects SpecialTime examples using post title/body as context.
3. `gemini.js` sends the selected examples, post title/body, toxicity tier and instructions for a child aged **6–15** to Gemini.
4. Gemini returns three short suggestions, rendered as **Context · Ask · Reflect**.
5. If no key is configured, the model times out, or Google's API returns an error, generic **fallback** suggestions appear instead.

**Current limitation:** The original backend does **not** pass the child's exact age to Gemini, even though the enhanced function accepts an optional `age` argument. Until you add age-aware settings, guidance is age-neutral across the 6–15 range. The Gemini prompt uses the post title and a body excerpt; it does not automatically include the sampled comments in the coaching request.

**To verify local dataset availability:**

```bash
cd backend
node -e "const p=require('./parenting_retrieval'); console.log(p.status(), p.count())"
```

Expect a `loaded-...-supportive-examples` status and a positive count. If the dataset cannot be loaded, the backend should continue to use its existing coaching behavior without claiming grounded examples.

## Troubleshooting

| Problem | Likely cause / action |
|---|---|
| Gemini tips say “Gemini unavailable” | Check terminal for `[gemini]` details. The interface uses fallback tips when requests fail. |
| `Gemini HTTP 503` | Google model temporarily overloaded; try another available model or later. |
| Gemini request times out | Increase `AbortSignal.timeout(...)` in `backend/gemini.js` if too short; confirm the chosen model responds with a **direct API test**. A longer timeout alone won't fix server overload. |
| `Gemini HTTP 404` | Model identifier not recognized or not available for the account/endpoint. |
| `Gemini HTTP 429` | Quota or rate limit reached. |
| Can't see SpecialTime examples | Check `parenting_data/specialtime.json` and run the retrieval status command above. |
| `uvicorn: command not found` | Activate `backend/ml_service/.venv` and install `requirements.txt`. |
| Safety check unavailable | Python service stopped, model load failed, Toxic-BERT download/inference issue, or fewer than five available comments. Check both terminals. |
| “Not enough comments” | At least five available comments are required; the backend does not invent a prediction. |
| Parent portal won't load | Verify Node server is listening on port 8787. |
| Wrong PIN / locked out | Verify the parent PIN; five incorrect attempts cause a five-minute lockout. |
| Pairing fails | Generate a fresh code; pairing codes expire after ten minutes. Check backend URL/network. |
| Pressing Space opens a button | Update to the waiting-only **Space Key Fix / Higher Jump** runner; keep focus/keyboard handlers from your latest `content.js`. |

**Important:** The backend begins Gemini generation when the thread is flagged, so reopening an existing review generally **does not retry** a failed call. Open a new flagged discussion after changing model settings. Restart Node after editing backend code.

## Privacy, security, and responsible use

- **Never commit** `backend/data.json`, `.env`, private keys, session or device tokens, `.venv`, or `node_modules`. The local `data.json` can contain parent account records, session tokens, pairing history, device identifiers, and key material.
- The prototype uses a JSON database, broad extension CORS/network permissions, and local HTTP. It is **not production-hardened**; add TLS, strict origin controls, robust authentication, secure secret storage, and appropriate safeguarding before any broader deployment.
- Raw Reddit text and selected SpecialTime excerpts may be transmitted to Google's Gemini API when enabled. Avoid including personally identifying information about minors in prompts.
- The public SpecialTime data is relevant to communication **style**; it is not a clinically validated online-safety intervention. Check and comply with Harvard Dataverse usage conditions, and cite the dataset and paper.
- Data from social platforms can contain disturbing material. Follow the platform's terms and appropriate privacy practices for minors.
- Because the app is installed in a browser rather than enforced at the operating-system level, a motivated user may be able to disable or bypass it.
